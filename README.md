# Tenn-Tech-Equipment-Inventory

This is going to be a proof of concept build for camera data extraction using similar systems to MEASUR (the system developed by ORNL) to allow future incorporation to the full system.

# Dependencies

- [Node.js](https://nodejs.org/en/download)
- Angular


## Running npm on windows (PowerShell)

If you get an error that says running scripts is disabled on this system run this code
```PowerShell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

## Install Angular CLI (npm)

To install Angular via npm run the following in PowerShell
```PowerShell
npm install -g @angular/cli
```

## Run Angular app

To run the Angular web app navigate to the Equipment_initial directory then run
```PowerShell
npm start
```
